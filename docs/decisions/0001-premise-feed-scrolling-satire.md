# 0001: The game is a feed-scrolling satire

Date: 2026-09-21
Status: decided
Kind: product
Issue: —

## Context

The repository existed as scaffolding only — no orientation doc, no
source, no spec. The name suggested food and scrolling, but nothing in
the repo settled what the game actually is, and `pm` is not permitted to
invent a premise.

## Decision

FoodScroller is a **feed-scrolling satire**: the player scrolls a
social-media-style food feed and makes choices. It is narrative and
choice-driven, not a reflex/arcade game. Scrolling is the core
interaction, not merely a UI affordance.

## Consequence

Rules out the endless-runner, cooking-sim and idle-collector readings.
Makes written content a first-class asset class rather than flavour text,
which is why the `writer` lane question is open (#2). Also
makes Constitution Principle I load-bearing: satire of a feed format
invites reference to real platforms and brands, and that boundary is not
yet drawn (#1).
